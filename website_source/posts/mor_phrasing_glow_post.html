MorPhrasing Glow

Striking, clever, and beautiful turns of phrase—unpacked. A lavender glow on near-black, set in IM Fell English, with a RuneLite-style rune frame drawn as a self-contained SVG border-image around posts and side panels.

Palette

  • Background #080808 (near-black), panels fade #080808 → #121212
  • Body text #ECECEB (16.9:1 contrast), muted #9d9db8 (7.6:1)
  • Accent / glow #b9b9fa lavender (10.9:1)

Import it

  1. Open the Theme Presets panel in the MorBlogger Theme Editor.
  2. Click the ⤓ (Import JSON) button to reveal Import Compendium Theme.
  3. Paste the preset link into the Remote JSON URL field.
  4. Click Import URL.
